# Explicit Sources and owner confirmation define itinerary truth

The Effective Itinerary is derived only from immutable Sources and explicit
Proposal confirmation by any one Decision Owner. Casual group chat is neither
stored nor itinerary evidence; it is deliberately excluded to protect privacy and
prevent an LLM or an ambiguous message from silently changing group plans.

## Considered Options

- Treat all group chat as evidence: rejected because it undermines privacy and
  makes accidental itinerary changes likely.
- Let the LLM update the itinerary directly: rejected because confirmation and
  provenance would be unreliable.
- Require unanimous owner approval: rejected for the MVA because it can block
  time-sensitive travel decisions.
